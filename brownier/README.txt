BROWNIE CLUB WEBSITE

FILES
- index.html: Home page
- recipe.html: Scalable brownie recipe
- flavors.html: Six interactive flavor cards
- timer.html: Working bake timer with sound
- game.html: Brownie stacking game
- about.html: About page and timeline
- styles.css: Styling for every page
- script.js: Navigation, animations, recipe controls, timer, sounds, and game
- favicon.svg: Browser tab icon

HOW TO OPEN
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Open index.html with the Live Server extension.

You can also double-click index.html, but Live Server is recommended.

IMPORTANT
Keep every file in the same folder. The two brownie photos are loaded from Unsplash, so they require an internet connection. Everything else works locally.
